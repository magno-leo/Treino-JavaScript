# ⏱️ Multi Cronômetro

Projeto criado para treinar JavaScript, partindo de um contador simples (clicar em um botão e somar a uma variável exibida na tela) e evoluindo até um gerenciador completo de múltiplos cronômetros.

## 📌 Sobre o projeto

A ideia inicial era simples: um botão que incrementava um número na tela. Conforme fui testando, comecei a adicionar novas funcionalidades para deixar o desafio mais interessante, até chegar em uma aplicação onde é possível criar vários cronômetros independentes, cada um contando o tempo no formato `hh:mm:ss`.

## ✨ Funcionalidades

- ➕ Criar novos cronômetros
- 🗑️ Remover cronômetros existentes
- ▶️ Iniciar contagem
- ⏸️ Pausar contagem
- 🔄 Zerar cronômetro
- 🔀 Reordenar cronômetros, trocando de posição com o vizinho
- 🕐 Exibição do tempo no formato hora:minuto:segundo

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript (Vanilla)

## 🎯 Motivação

Este projeto foi desenvolvido como exercício prático de lógica de programação e manipulação do DOM, evoluindo de forma incremental: cada nova funcionalidade era um novo desafio para reforçar conceitos de JavaScript.
